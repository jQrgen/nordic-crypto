Nexa

Nordic Crypto Nexaプール – 独立した北欧の暗号資産ジャーナリズムを支える1%の手数料

手数料の使いみち

始める

Nexa のマイナーをこのプールに向けます。ユーザー名は自分の Nexa アドレスです。

Stratum URL

stratum+tcp://pool.nordiccrypto.no:3333

ユーザー名は Nexa アドレスです。ワーカー名は任意です: アドレス.ワーカー

まだ Nexa アドレスがありませんか？こちらで作成できます: Wally ウォレット

マイナーの例

  • lolMiner

    lolMiner --algo NEXA --pool stratum+tcp://pool.nordiccrypto.no:3333 --user nexa:ADDRESS

  • BzMiner

    bzminer -a nexa -p stratum+tcp://pool.nordiccrypto.no:3333 -w nexa:ADDRESS

  • Rigel

    rigel -a nexapow -o stratum+tcp://pool.nordiccrypto.no:3333 -u nexa:ADDRESS

  • SRBMiner

    SRBMiner-MULTI --algorithm nexa --pool stratum+tcp://pool.nordiccrypto.no:3333 --wallet nexa:ADDRESS

    自分の統計

    Nexa アドレスを検索します。

    条件

    • プール手数料は 1% です。
    • 報酬は pay-per-last-N-shares です。窓は、仕事量の合計がネットワーク難度2つ分になる最新のシェアです。
    • 最低支払額は 1,000,000 NEX です。
    • 支払いはおよそ1時間に1回で、コインベースが 5,000 承認されてから行われます。

    透明性

    このプールは Nordic Crypto が運営しています。

    手数料はプールの運用と、独立した北欧の暗号資産ジャーナリズムに使われます。

    マイナーはプールからブロック候補を受け取り、プルーフ・オブ・ワークを探します。シェアはプールの目標に達した証明です。シェアがネットワークの目標にも達すると、プールはそれをブロックとして提出します。コインベースが成熟したあと、報酬は窓の中のシェアに分配され、手数料は別に取り置かれ、各アドレスへプールのウォレットから支払われます。
