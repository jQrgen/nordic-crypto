# Rendered files (not in git)

Put the country film here when it exists:

- `video-no.mp4`, `video-se.mp4`, `video-dk.mp4`, `video-fi.mp4`, `video-is.mp4`
- optional `subs-XX.vtt` (English WebVTT)

`tools/regulation_videos.py` copies a file into the site only when it is in this folder. MP4s are gitignored. A missing file leaves the slot as a placeholder with the title, narrator notes and sources.
