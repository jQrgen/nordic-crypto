News stories

Stories in data/news.json. status is the editorial state: pending, published, rejected or merged. The public API lists published stories that have a summary. Editor fields stay in the file and are left out of /api/v1/.

Файл data/news.json · JSON Schema

Сторінка

  • /

API

  • /api/v1/news.json — Published stories, newest first
  • /api/v1/news/{id}.json — One story
  • /api/v1/news/latest.json — The 25 newest stories, notifier fields only
  • /api/v1/news/by-country/{country}.json — NO, SE, DK, FI, IS, NORDIC or EU
  • /api/v1/news/by-topic/{topic}.json — One topic
  • /api/v1/news/topics.json — Topic index

Зв’язки

  • source → sources many-to-one — Outlet id in sources.json
  • also_covered_by[].outlet → sources many-to-one — Other outlets on the same event
  • id → title-i18n one-to-one — Our headlines, when we wrote them
  • id → blurbs one-to-one — Front-page blurb, when one is written

Events

Calendar events. data/events.json is the working list, archive/events.json is what the public calendar keeps, and data/events_backfill.json is the previous-events backfill. sponsored is null, false, true, or the sponsor's name, and is never Kaupr. The calendar status upcoming, ongoing or past is computed from start and end and is not stored.

Файл data/events.json, archive/events.json, data/events_backfill.json · JSON Schema

Сторінка

  • /calendar/
  • /calendar/previous/

API

  • /api/v1/events.json — Public events, soonest start first, including past events
  • /api/v1/events/{id}.json — One event
  • /api/v1/events/upcoming.json — Events that have not ended
  • /api/v1/events/past.json — Finished public events
  • /api/v1/events/previous.json — Finished calendar events plus the backfill
  • /api/v1/events/by-country/{country}.json — One country

Зв’язки

  • sponsored → sponsors many-to-one — Null, false, true, or the sponsor's name
  • id → talks one-to-many — Talks recorded at this event
  • id → event-descriptions one-to-one
  • id → event-redirects one-to-one — A removed duplicate points at the kept id
