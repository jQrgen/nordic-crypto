Get started

Point a Nexa miner at this pool. The username is your Nexa address.

Stratum URL

stratum+tcp://pool.nordiccrypto.no:3333

The username is your Nexa address. A worker name is optional: address.worker

No Nexa address yet? Create one in the Wally wallet

Miner examples

  • lolMiner

    lolMiner --algo NEXA --pool stratum+tcp://pool.nordiccrypto.no:3333 --user nexa:ADDRESS

  • BzMiner

    bzminer -a nexa -p stratum+tcp://pool.nordiccrypto.no:3333 -w nexa:ADDRESS

  • Rigel

    rigel -a nexapow -o stratum+tcp://pool.nordiccrypto.no:3333 -u nexa:ADDRESS

  • SRBMiner

    SRBMiner-MULTI --algorithm nexa --pool stratum+tcp://pool.nordiccrypto.no:3333 --wallet nexa:ADDRESS

    Terms

    • The pool fee is 1%.
    • Rewards use pay-per-last-N-shares. The window is the newest shares whose work adds up to two network difficulties.
    • The minimum payout is 1,000,000 NEX.
    • Payouts run about once an hour, and only after the coinbase has 5,000 confirmations.

    Transparency

    This pool is run by Nordic Crypto.

    The fee pays for hosting the pool and for independent Nordic crypto journalism.

    Your miner takes a block candidate from the pool and searches for a proof of work. A share is a proof that meets the pool target. When a share also meets the network target, the pool submits it as a block. After the coinbase matures, the reward is split across the shares in the window, the fee is set aside, and each address is paid from the pool wallet.
