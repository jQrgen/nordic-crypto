Nexa

Pool Nexa de Nordic Crypto – des frais de 1 % qui financent un journalisme crypto nordique indépendant

À quoi servent les frais

Commencer

Pointez un mineur Nexa vers ce pool. Le nom d'utilisateur est votre adresse Nexa.

Adresse stratum

stratum+tcp://pool.nordiccrypto.no:3333

Le nom d'utilisateur est votre adresse Nexa. Un nom de worker est facultatif : adresse.worker

Pas encore d'adresse Nexa ? Créez-en une dans le portefeuille Wally

Exemples de mineurs

  • lolMiner

    lolMiner --algo NEXA --pool stratum+tcp://pool.nordiccrypto.no:3333 --user nexa:ADDRESS

  • BzMiner

    bzminer -a nexa -p stratum+tcp://pool.nordiccrypto.no:3333 -w nexa:ADDRESS

  • Rigel

    rigel -a nexapow -o stratum+tcp://pool.nordiccrypto.no:3333 -u nexa:ADDRESS

  • SRBMiner

    SRBMiner-MULTI --algorithm nexa --pool stratum+tcp://pool.nordiccrypto.no:3333 --wallet nexa:ADDRESS

    Mes chiffres

    Chercher une adresse Nexa.

    Conditions

    • Les frais du pool sont de 1 %.
    • Les récompenses suivent le pay-per-last-N-shares. La fenêtre est constituée des parts les plus récentes dont le travail vaut deux difficultés du réseau.
    • Le paiement minimum est de 1 000 000 NEX.
    • Les paiements partent environ une fois par heure, et seulement après 5 000 confirmations du coinbase.

    Transparence

    Ce pool est opéré par Nordic Crypto.

    Les frais paient l'hébergement du pool et un journalisme crypto nordique indépendant.

    Votre mineur demande un candidat de bloc au pool et cherche une preuve de travail. Une part est une preuve qui atteint la cible du pool. Quand une part atteint aussi la cible du réseau, le pool la soumet comme bloc. Une fois le coinbase mature, la récompense est répartie sur les parts de la fenêtre, les frais sont mis de côté, et chaque adresse est payée depuis le portefeuille du pool.
