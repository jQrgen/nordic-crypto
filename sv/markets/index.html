Priser på nordiska börser

Senast, köp och sälj som börsen publicerade dem. Det här är marknadsdata, inte investeringsrådgivning. Ett pris i norska kronor är inte samma siffra som ett pris i euro, svenska kronor eller danska kronor. Raden ovanför varje valuta är medelvärdet av börserna som noterar den. Volym visas bara när en börs har publicerat den.

Market data, not investment advice. Each figure is the value published by the named exchange at fetched_at. Nordic Crypto does not set these prices and does not tell anyone to buy or sell.

Börser som inte är med

De här är kontrollerade och utelämnade för att det inte finns en öppen kurs.

  • Safello (SE): GET https://api.safello.com/v2/market/tickers requires an OAuth token with the market scope. No unauthenticated ticker was found.
  • Goobit (BTCX) (SE): No public ticker was found. btcx.se redirects to bt.cx, and https://bt.cx/sv/api/ticker returns 404.
  • Trijo (SE): No public unauthenticated ticker API was found.
  • Northcrypto (FI): No public ticker was found. Common paths on northcrypto.com (/api, /api/markets, /api/tickers) return 404.
  • Kvarn X (FI): The documented REST API is a partner integration for customer orders, not a public ticker.
  • Danish-registered exchange (DK): No Danish-registered exchange with a public ticker was found. DKK pairs published by Firi and NBX (both Norway) are included.
  • Icelandic exchange (IS): No Icelandic crypto exchange with a public ticker API was found. Monerium issues e-money and does not publish a spot-market ticker.

Tabellen fylls från det offentliga JSON-gränssnittet, som uppdateras ungefär en gång i timmen. Firi och Coinmotion låter också den här sidan fråga börsen direkt med några minuters mellanrum. NBX tillåter inte det från en webbläsare, så de raderna följer timfilen.
